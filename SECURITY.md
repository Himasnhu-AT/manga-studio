# Security

Manga Studio runs on your Mac. Its backend listens on `127.0.0.1:7860` only, and the MCP bridge
talks to that backend. Your stories, images and settings stay on the machine.

## Reporting a vulnerability

Please report security issues privately through
[GitHub security advisories](https://github.com/Himasnhu-AT/manga-studio/security/advisories/new),
not in a public issue. Include the version (or commit), what an attacker can do, and how to
reproduce it. You'll get a reply within a week.

## Supported versions

Fixes go into the latest release and `main`.
